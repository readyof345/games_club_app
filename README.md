# Games Club Full Flutter App

This is a runnable Flutter starter app based on the supplied screenshot.

Included:
- Login screen with local session
- Home dashboard
- Banner carousel
- Customer support dialog
- Games cards
- Upcoming matches
- Join-match flow (non-monetary)
- Notifications
- Profile page
- Local logout/session storage
- Dark UI matching the supplied style

Run:
1. Install Flutter + Android Studio.
2. Extract this ZIP.
3. Open the folder in Android Studio or VS Code.
4. Run `flutter pub get`.
5. Run `flutter run`.

For a production release, connect a real backend such as Firebase/Supabase for authentication, match data, profiles, notifications and support.

This starter intentionally does not implement betting, deposits, withdrawals, gambling, or cash-prize mechanics.
